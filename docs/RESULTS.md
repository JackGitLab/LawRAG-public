# 成果与验证

本页整理截至 2026-10-11 的已验收工程成果。2026-10-12 的求职展示整理不重新采集真实模型数据，不把历史结果写成本轮实测。

## 1. 检索：固定题集上的策略对比

- 历史修订版回归集共 55 题：45 道库内题、10 道库外题。
- 纯向量检索 Hit@3 为 42/45（93.3%），hybrid_rerank 为 45/45（100%）。这是目标法条进入前三条的比例，不是答案正确率。
- 比较过 7 种策略；默认方案组合向量、BM25、RRF 和重排。历史样本和题集版本不可混用。
- 实现：[检索代码](../app/ask.py)；输入：[冻结回归题集](../tests/regression_questions.json)；工具：[策略比较](../tests/run_strategy_comparison.py)。口径见 [DESIGN](DESIGN.md#8-检索方案评估)。

## 2. 评测：让评分对应真实答案

新增 40 个冻结场景，覆盖库内问答、回答边界、工具路由与多轮任务。实现答案内容身份校验、冻结题集身份校验、固定计划分母和待审标注隔离。

**接受的是评测实现，不是法律正确率。** 语义评分仍为执行者初评，4 道法律标注题待复核。引用已审 46、待标注 4，92% 是标注覆盖率，不能称为回答正确率。

- 实现：[质量评测工具](../tests/run_quality_evaluation.py)。
- 回归：[评测测试](../tests/test_quality_evaluation.py)、[题集校验](../tests/test_evaluation_cases.py)。
- 历史依据：最终独立验收（未公开的历史记录）。

## 3. 工具：多轮补参、纠正与取消

为计算请求保存待补参数，处理同任务补充、无效更正、取消和新任务切换；参数齐全后调用现有计算器，执行失败不会标成完成。

- 实现：[Agent 图](../app/graph.py)、[确定性工具](../app/tools.py)。
- 回归：[多轮计算测试](../tests/test_calculation_clarification.py)。
- 边界：[详细行为说明](STAGE2_CLARIFICATION.md)。不支持一个会话中多个并行待办计算任务；真实模型未覆盖项保持未验证。
- 历史依据：最终独立验收（未公开的历史记录）。

## 4. 性能：缺参追问跳过无效检索

将多轮图从“先检索后路由”调整为“先路由”；确定性缺参分支直接追问，不执行向量、BM25 或重排。

| 指标 | 优化前 | 优化后 | 解释 |
| --- | ---: | ---: | --- |
| 检索逻辑集合 | 24 | 20 | 每组包含 vector / BM25 / rerank；本批减少 16.7% |
| LLM 逻辑调用 | 36 | 36 | 没有减少模型逻辑调用 |
| CALC T1 首段中位耗时 | 5278.6 ms | 3682.8 ms | 确定性追问首段，各 3 次正式样本 |
| CALC 两轮任务中位耗时 | 20563.5 ms | 18826.9 ms | 两轮耗时之和，各 3 次正式样本 |

每批为 4 场景、6 轮，预热 1 遍、正式 3 遍，共 24 个业务请求。基线为 `perf-20261011-live1`，优化后为 `perf-20261011-opt1-1`。两批的其他场景也有观察变慢；**不推导统计显著性、稳定生产收益或完整成本下降**。已知费用变化包含输出 token 波动，未知价格继续单列。

- 方法：[PERFORMANCE](PERFORMANCE.md)。
- 工具：[测量 CLI](../tests/run_performance_baseline.py)、[优化后采集入口](../outputs/live_opt1_20261011/run_capture_opt1.py)。真实采集会请求外部服务。
- 回归：[测量测试](../tests/test_performance_baseline.py)、[包装器测试](../tests/test_opt1_post_capture_20261011.py)。
- 历史依据：测量实现验收（未公开的历史记录）、基线验收（未公开的历史记录）、优化实现验收（未公开的历史记录）、真实对照复测（未公开的历史记录）。
- 清理实现后来经专项复验（未公开的历史记录）关闭；历史首次 `port_released=false` 保持原样。

## 5. 证据可获得性

公开仓库包含代码、冻结题集、回归测试、采集工具和价格快照。本文历史结果来自原项目保存的开发与验收材料；完整原始档案和旧提交历史未公开。本文不是外部读者已独立复核这些历史结果的证明。

原始事件、模型输出与独立探针位于本地 `logs/`，不随克隆分发。报告和哈希不能替代这些原始数据；没有对应数据时，可以检查实现、执行离线回归，**不能独立重算原历史批次的全部结果**。本地的旧报告、错误档案和原始数据不因展示整理而删除。
